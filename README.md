# Crowell's Media Group — Landing Page

Marketing landing page for Crowell's Media Group — a small, local studio building digital presence for businesses in Jasper, AL.

## Stack

- **Static HTML + CSS** (single page, no framework)
- **Google Fonts** via CDN: Lora, Instrument Sans, Bricolage Grotesque, Nothing You Could Do
- **Form backend:** [Formsubmit.co](https://formsubmit.co) — leads delivered to `crowelle868@gmail.com`
- **Hosted on:** Vercel
- **Repo:** GitHub

## Local preview

Open `index.html` in any browser. No build step required.

## Updating content

The page is a single `index.html` file. Edit it in any text editor, commit + push to GitHub, and Vercel will auto-deploy the new version within 30 seconds.

## Brand system

- **Navy:** `#1a2a4a`
- **Green:** `#6cba3c`
- **Cream:** `#faf7f0`
- **Cream deep:** `#f2ede0`
- **Muted text:** `#5a6479`

## Design philosophy

"Storefront Editorial" — a duotone navy + green editorial aesthetic over cream. Generous whitespace, hairline rules, display serif headlines, sans-serif body. Modeled after a thoughtful regional design annual rather than a typical SaaS landing page.
